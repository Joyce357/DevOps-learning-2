S3 Classroom Demo

Show CORS on S3 without a custom server.

Host this page in one S3 website bucket, store one JSON file in a second bucket with no CORS, and store another JSON file in a third bucket with CORS allowed. Students will see one JavaScript fetch fail and one succeed, even though both objects are publicly reachable.

What proves the block?
If Open directly works in a new tab but Fetch blocked object fails in this page, the object exists and S3 served it, but the browser refused to expose it to JavaScript because the bucket did not allow this origin.

Step 2: Teaching script

  1. Open this page from the frontend S3 website bucket.
  2. Paste the blocked object URL and the allowed object URL.
  3. Click Open directly for the blocked object and show that the JSON loads in a new tab.
  4. Come back and click Fetch blocked object. The browser should block JavaScript access.
  5. Open DevTools and show the console error and the missing Access-Control-Allow-Origin header.
  6. Then click Fetch allowed object and compare the successful result.
S3 is perfect for teaching GET/download CORS. If you also want to teach JSON POST preflight, keep using the local Python API demo or switch the API side to API Gateway + Lambda.
