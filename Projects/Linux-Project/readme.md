**Linux Automation Toolkit Project** 

Project Title ; **Team4Tech Solutions Internal Linux Automation Project**

**Background** 

Welcome to your group project.

For this assignment, you will work as if you are part of a junior DevOps / Operations team at Team4Tech Solutions. Your team has been asked to build a small internal automation toolkit that helps system administrators automate common Linux tasks.

This project is designed to simulate a real working environment. That means your team will not only write Bash scripts, but will also work together using professional tools and processes such as:

+ Git
+ GitHub
+ Bash shell scripting
+ Jira
+ team collaboration
+ pull requests
+ documentation
+ presentations

The purpose of this project is to help you practice both technical skills and teamwork skills in a way that reflects how real engineering teams operate in a company.

**Project Objective**

The objective of this assignment is to build a shared Linux Automation Toolkit using Bash scripts while working as a collaborative team.

By the end of this project, your team should be able to demonstrate:

+ how to use Git and GitHub in a team environment
+ how to create and manage a GitHub Organization
+ how to invite team members and the instructor into the organization
+ how to track work using Jira
+ how to collaborate using branches and pull requests
+ how to write useful Bash scripts that solves real problems
+ how to document your work clearly
+ how to present your work professionally as a team


**Project Scenario** 

Team4Tech Solutions wants to reduce repetitive manual work performed by Linux administrators. Instead of logging into servers and doing everything by hand, the company wants a team to build a toolkit of Bash scripts that can automate common operational tasks.
Your team has been assigned to `design, build, track, document, and present this solution`.
You are expected to behave like a real project team inside a company.

**Team Structure**

Each group will have 10 engineers.
Since you already have team leads, the group should function as follows:

**Team Leads**

The team leads are responsible for:

+ organizing the team
+ helping distribute work
+ ensuring everyone participates
+ monitoring progress
+ helping manage Jira tasks

+ supporting the final presentation

**Team Members**

Each team member is responsible for:

+ creating or using their own GitHub account (most of u have this already)
+ joining the team GitHub Organization
+ contributing to the repository
+ completing assigned Jira work
+ collaborating with the team
+ participating in pull requests or reviews
+ speaking during the presentation

This is a team assignment, but every individual must contribute.

**Part 2: Project Task**

Your team must build a Linux Operations Automation Toolkit for Team4Tech Solutions.
This toolkit must contain Bash scripts that automate useful Linux administration tasks.

**Examples of script ideas**

Your team may choose scripts such as:

+ user creation and management
+ locking or deleting user accounts
+ backup of files or directories
+ disk usage checks
+ memory and CPU checks
+ service status checks
+ log archiving
+ permission auditing
+ package update checks
+ simple system reports

You may decide as a team which scripts to include, but the project must be `useful`, organized, and collaborative.

Part 6: GitHub Collaboration Rules

To simulate a real company environment, your team must follow these GitHub rules:

+ do not push directly to main follow github workflow we studied in class and if possible setup branch protection rules
+ use separate branches for different tasks
+ use pull requests for major changes
+ use meaningful commit messages
+ keep the repository clean and organized
+ show evidence of teamwork through commits, branches, and pull requests

`Examples of branch names`

feature/backup-script
feature/service-check

`Examples of commit messages`
